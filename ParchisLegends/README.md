# Parchís Legends

Este es un prototipo simplificado de la aplicación **Parchís Legends** desarrollada con React Native CLI. Incluye la estructura de carpetas, configuración básica y componentes de muestra para comenzar a desarrollar un clon de Parchís Star.

## Scripts

- `npm start` inicia Metro.
- `npm run android` compila y lanza la app en Android.
- `npm run ios` compila y lanza la app en iOS (requiere macOS).

## Nota

Este código es un esqueleto inicial que no implementa todas las funcionalidades solicitadas debido a la complejidad del proyecto.
